# 划水纪 (HuaShuiReader)

> 一个简简单单、只为上班摸鱼看小说顺手而写的小工具。

无边框极简窗口，界面干净，支持一键吸色融进 IDE 或办公背景、全局老板键秒隐藏、连续双向无缝滚屏，支持本地 TXT/MD 与开源阅读规则。纯绿色单文件运行，所有缓存收敛在本地目录，不写系统 C 盘，退出即干净。

---

## 核心摸鱼体验

- **桌面隐蔽伪装**：
  - 无原生厚重边框，支持任意拖拽边缘调整大小，缩成巴掌大扔在屏幕角落。
  - **跨窗口一键吸色**：点击吸色吸管，点一下 VS Code、IDEA 或聊天软件背景，阅读器底色立刻融为一体，不仔细看看不出来。
- **顺手防查岗**：
  - **全局老板键**：随时按快捷键一秒隐匿/呼出窗口。
  - **快速隐匿**：焦点在窗口时按 `Esc` 键光速最小化。
- **舒服的阅读控制**：
  - **连续双向滚屏**：键盘 `Space` / `J` 下滚、`K` 上滚，滚轮无缝穿透跨章，不需要频繁手动翻页。
  - **视觉微调**：内置系统字体与自定义字体切换、字号、行距、面板色、弱化文字色自由搭配。
  - **小标题浮动**：向下滚屏时顶栏动态浮现当前章节小标题，随时知道读到了哪。
- **本地与网络阅读**：
  - 支持直接拖入本地 `.txt`、`.md` 文件，自动分卷分章排版与编码识别（GBK/UTF-8 自动检测）。
  - 支持导入 Legado（开源阅读 3.0）JSON 书源，支持多并发搜索、正文智能净化与跨章预缓存。
- **真正纯绿色便携**：
  - 程序配置文件、本地书库、章节缓存以及 WebView2 用户运行数据全部收敛在 exe 旁边的 `data/` 目录。
  - 绝不在系统 `%APPDATA%` 或 C 盘写入垃圾，放 U 盘里插上就能看，拔走不留痕迹。

## 快捷键一览

| 按键 | 说明 |
| :--- | :--- |
| `Ctrl+Alt+M` | 全局老板键（隐藏 / 呼出窗口） |
| `Esc` | 快速最小化窗口 |
| `Space` / `PageDown` / `J` | 向下滚动半屏 |
| `PageUp` / `K` | 向上滚动半屏 |
| `F11` | 最大化 / 还原窗口 |

## 下载与运行

到 [Releases](../../releases) 页面下载最新发布的压缩包，解压后双击 `huashuireader.exe` 即可直接使用。

> 注：系统需要 Windows 10 / 11（自带 WebView2 运行时，一般电脑都有，没有的话微软官网装一下就行）。

## 从源码编译

如果想自己改代码或本地打包：

1. **环境准备**：
   - 安装 [Go](https://go.dev/) 1.22+
   - 安装 [Wails v3 CLI](https://v3.wails.io/)：
     ```bash
     go install github.com/wailsapp/wails/v3/cmd/wails3@latest
     ```
2. **构建 Windows 可执行程序**：
   ```bash
   # 克隆项目
   git clone https://github.com/cycocyco/HuaShuiReader.git
   cd HuaShuiReader

   # 生产编译（自动嵌入前端静态资源与 Windows 清单图标）
   wails3 task build
   ```
   构建产物将在 `bin/huashuireader.exe` 生成。
